# Статья: PAYPHONE

Стек VPN написан с нуля на Rust 2024. IP с TUN едет в unreliable QUIC datagrams: внутренний TCP сам переживает потери, внешний надёжный стрим дал бы TCP-over-TCP.

## Зачем обфускация

Голый QUIC узнаваем по long header. Поверх TLS — короткий XOR с PSK, чтобы слепой probe не получал даже QUIC-ответ. Это не маскировка под чужой сайт. На TCP 443 probe без ключа может уехать на настоящий сайт (REALITY).

## Пример кадра

16 байт заголовка + payload. Типы с нарочно дурацкими именами: `WhatsUpDude`, `AllGoodDude`, `Data`, `Ping`/`Pong`. Длина и version жёстко валидируются.

Полный рассказ (инженерный, с ловушками macOS): `docs/habr-payphone.md`. Сюда не копируем статью целиком — только карта решений.
